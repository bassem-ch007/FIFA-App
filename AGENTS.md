# Project instructions

This repository implements TP2 React: Components, Props and dynamic rendering.

For work related to the TP exercises or application architecture,
read `docs/TP2_SPEC.md`.

Preserve the exercise progression:
Ex1 -> Ex2 -> Ex3 -> Ex4.

Reuse shared components rather than duplicating implementations.

Keep the TP static and simple: no hooks, search, filters, or feature state.
Use explicit props, four flat shared components, and one stylesheet.

Do not add dependencies unless explicitly approved.
